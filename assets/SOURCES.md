# 素材来源与处理说明

本目录下的图片是为本插件搜集的《绝区零》千夏（Sunna）美术素材：`sunna-*.webp`，以及插件原有的 `portrait.webp`。
当前随包分发的共 **2.96 MB**（中途曾精简到 1.16 MB，后因"影画"主题需要背景候选又放回，见文末审计）。

- **来源 A**：[萌娘共享 · 分类:千夏(绝区零)](https://commons.moegirl.org.cn/Category:%E5%8D%83%E5%A4%8F(%E7%BB%9D%E5%8C%BA%E9%9B%B6))（`sunna-01`、`02`、`04`、`07`–`13`）
- **来源 B**：官方 Q 版表情的**源文件**（`sunna-14-chibi-*`）—— 144×144 PNG、自带 alpha、**文件没有扩展名**（所以双击打不开），共 7 个，文件名本身就是表情名
- **来源 C**：`portrait.webp` 是插件原有的默认素材。**它同样是这个角色的官方立绘**（与 `sunna-04` 同一造型），属来源 A 一类，只是进包更早、此前没有登记过
- **站点授权**：萌娘共享的页面内容按 CC BY-NC-SA 4.0 提供
- **角色版权**：《绝区零》/ miHoYo / HoYoverse

两处选择器都在画板里可见：**右下挂件**有七个表情（`LAYERS` 的 `pet.variants`，所有主题共用），
**"影画"主题的背景氛围**有六个候选（该主题 `background.variants`），固定顺序：

- **跟随明暗 · 浅 09 / 深 08** —— 默认项，画板在它下面画一个圆点。它的**色块**是一张两张色版并排的
  合成缩略图（`sunna-bg-auto.webp`，本插件自己拼的，只用于显示），这样它不会和下面的"亮"撞脸；
- `07` **绿粉** / `08` **暗** / `09` **亮** —— 意象影画的三张色版，各自独立可选；
- `10` **旧梦的安可曲** / `11` **除夕贺图** —— 两张场景海报。

除默认项外，每个候选都用自己那张画同时服务浅色与深色底色，所以**深色底下每一块都能切出效果**——
包括单独选 `09`。这正是"深色下切 08/09 没反应"的修法：把默认独立成一项，而不是让它和 `09` 合为一项
（合在一起时，深色下点 `09` 等于回到默认，永远只能得到 08）。主题自身声明的 `file`/`fileDark`
（09 / 08）只在画板尚未挂载时作为样式表兜底。

`sunna-12` 与 `sunna-13` 按要求**留在包内但不进候选**，画板里不会出现。挂件还能拖到窗口任意位置。

> 移出与从未入包的素材都留在 `sunna-assets/` 下：移出的在 `_spare/`，其余用 `_publish_assets.py` 可重新生成。

## 处理方式

1. **格式与尺寸**：原始 PNG/JPG 统一转 webp（quality 88，Q 版小图用 92），按类别限制最长边 —— 立绘 1600、横版插画 2400、超宽 3200、竖版海报 2000、图标 256。目的是不让插件包背上印刷级原图。
2. **抠图**：`sunna-02-teatime.webp` 由 `rembg` 的 `isnet-anime` 模型（动漫立绘专用）抠出，随后三步收尾 —— 轮廓收缩 3px（切掉被判成前景的海报底色，也就是那圈粉色描边）、边缘颜色取最近的不透明像素（避免背景色向内扩散）、1.5px 羽化（把硬边还原成自然过渡）。整条链路在 `sunna-assets/_rematte_02.py`，改常数重跑即可复现。早期用 `u2net` 抠的版本在深色界面上有明显的粉色轮廓，已弃用。
3. **镜像副本**：`-flip.webp` 由同一张成品水平翻转后编码，不是从已发布的 webp 二次转码；透明通道与原图逐像素一致（alpha maxdiff 0）。所以 `02` 与 `02-flip` 是一对朝向相反、剪影严格对称的立绘。
4. **裁边**：`01`、`02`、`04` 的画框空白都被裁掉（`sunna-assets/_trim_publish.py`）。侧栏是按**画框**高度算立绘大小的，画框里留白越多、同一尺寸下人物就越小，而且底部留白还会让脚底浮在侧栏底边之上 —— 这个悬浮量随尺寸变化，没法用一个百分比位置配对。`02` 原本顶部留 12%、底部留 6%，裁边后画框的 98.9% 都是人物（`01` 是 99.6%，`04` 是 98.7%），于是同一套尺寸设置就能让不同主题的立绘有相同身高，`position: 100%` 也让脚底落在同一条线上。
5. **表情**：`sunna-14-chibi-*` 直接来自那 7 个官方源文件（`sunna-assets/_chibi-src/`，另在 `_chibi-named/` 留了一份补上 `.png` 扩展名的副本），**没有抠图**。只做了 2× Lanczos 放大 + 轻锐化：144px 的源在 1.5 倍屏上要显示到 180 物理像素，先在无损源上放大、再让浏览器缩回去，比反过来做插值干净得多。
6. **未抠图的素材**：`03` 与 `07`–`13` 是场景海报而非透明人物立绘 —— 人物与装饰、排版文字、光效交织，分割模型无法把它们干净分离（实测两个模型分别产出碎片和空白）。这些素材以整幅形式保留，作背景/场景用，不做透明化。

1. **包内的素材里，多数只做了转码**。18 个文件里只有 `sunna-01`（裁边）、
